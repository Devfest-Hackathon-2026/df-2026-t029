## 2. 決定事項：まとめてフォロー（Ff-1）

### 2.1 原因

- `FollowAllMembersButton`（`lib/features/oshi/group_members_panel.dart`）が、メンバーの数だけ `runFollowAction` を順に `await` している。1人ごとにトランザクション（推しと `users/{uid}` を読んで書く）が走るので、8人なら8回、順に1人ずつ切り替わって見える。

### 2.2 直し方

- `FollowRepository`（`lib/repositories/follow_repository.dart`）に **`followMany(uid, targets, {displayName})`** を足す。
  - 1つのトランザクションで、対象の推しのドキュメントをすべて読んで（承認済みか）、`users/{uid}` を読み、まだフォローしていない ID だけを `FieldValue.arrayUnion([...])` で**1回で**書く（種別ごと）。
  - 上限（種別ごとに200）を超える分は足さない。
  - 戻り値は `({int added, int skipped})`（足した人数・上限や申請中で足さなかった人数）。
  - `users/{uid}` が無いときの作り方は `follow` と同じ（displayName・createdAt・空の配列を補う）。
- ルールは変えない（`followingOshiIds` は200件までのリストであればよい。1回で複数足しても通る）。
- `FollowAllMembersButton._followAll` は `followMany` を1回だけ呼ぶ。終わったら今と同じ形のメッセージ（「8人をフォローしました」など）。フォロー状態の購読が1回で変わるので、メンバーの行のボタンも一度に「フォロー中」になる。

## 5. 決定事項：ホームの「推しの新しいライブ」（Ff-4・Ff-5）

### 5.1 中身

- **フォロー中の推し**（最推しだけではない）のライブのうち、次をすべて満たすもの：
  - まだ終わっていない。
  - **登録されてから14日以内**（ライブの `createdAt`）。AI が公式サイトから登録したもの（add_L）も、人が登録したものも含む。
  - **自分のライブ一覧に入っていない**（`myLiveIdsProvider` に無い）。
- 登録の新しい順に最大5件。1件も無ければ区画ごと出さない。
- YouTube の動画はホームに出さない（推しのページの「最新の動画」だけ）。`HomeOshiNews`（add_P 5.3）と `favoriteOshiNewsProvider` は使わなくなるので消す。`oshiNews` の書き込み（Functions）はそのまま（推しのページで使う）。

### 5.2 データ

- `Live`（`lib/models/live.dart`）に `createdAt`（`DateTime?`。読むだけ。`toFirestore` には入れない）を足す。
- `lib/providers/live_providers.dart` に `newOshiLivesProvider`（`Provider.autoDispose<AsyncValue<List<LiveListEntry>>>`）：`followingOshisProvider` から `FollowTargets.fromFollowing` を作り、`liveSearchProvider((targets: ..., query: ''))` の結果を 5.1 の条件で絞って並べる。

### 5.3 見た目（`lib/features/home/home_new_oshi_lives.dart` の `HomeNewOshiLives`）

- 見出し「推しの新しいライブ」（右に「すべて見る」→ `/lives`）。ヒント「フォロー中の推しに、新しく登録されたライブです。」
- 1件は白い箱（`HakoBox`）のカード：
  - 左に日付の札（`HakoDateBadge`。次の公演の日）。
  - 右にライブ名（2行まで）、出演者（推しの名前）、次の公演の時刻と会場。
  - 札（チップ）：AI が登録したものは「公式サイトから自動登録」、ほかは「新しく登録」。その横に「◯日前」。
  - 右下に **「参戦する」** ボタン（`FilledButton`。押すと自分のライブ一覧に追加。今の「推しの今後のライブ」の追加と同じ処理で、続けて Google カレンダーにも入れられる）。追加したらカードが消える（一覧に入ったので条件から外れる）。
  - カードを押すとライブ詳細。
- 処理中はボタンを押せなくする。失敗したら「ライブ一覧に追加できませんでした。もう一度お試しください」。

## 6. 決定事項：メンバーの推しのページの YouTube（Ff-6）

### 6.1 方針

- 公式 YouTube の無い**個人**（グループのメンバーなど）のページでは、「最新の動画」の代わりに **「YouTube の動画（◯◯で検索）」** を出す。YouTube Data API の検索で、その人の名前（と所属グループの名前）で探した動画を並べる。
- 公式 YouTube のある推し（グループ・ソロ）は、今の「最新の動画」のまま。
- 個人のページでは、所属グループの動画は出さない（グループのページで見られる）。`_Videos` は、個人なら自分のキーのお知らせだけを使う。
- **X**：推しに `officialX` があれば、今も「公式」の区画に出ている。CUTIE STREET のメンバーは L-4d の前の取得で本人の X が入っている（真鍋凪咲さんだけグループの X が入っているので、コンソールで直すか消す）。新しく増えたメンバーの X は、今は申請のときの入力かコンソールだけで入る（9章）。

### 6.2 Functions：Callable 関数 `searchOshiVideos`

- 入力 `{id}`（個人の ID）。ログインしていなければ `unauthenticated`。推しが無い・承認前なら `{status: 'skipped', videos: []}`。
- 検索の語：`"<名前>" <所属グループの名前>`（グループが無ければ名前だけ）。`search.list?part=snippet&type=video&q=...&maxResults=6&regionCode=JP&relevanceLanguage=ja`（1回100ユニット）。
- **キャッシュ**：`oshiVideoSearch/person_{id}` に `{query, videos: [{videoId, title, channelTitle, publishedAt}], fetchedAt}` を書き、**24時間以内ならそれを返す**（API を呼ばない）。アプリはこのコレクションを読まない（ルールは今のまま拒否。Callable の戻り値だけを使う）。
- 出力 `{status: 'ok', query, videos}`。API の失敗は `internal`。
- `secrets: [YOUTUBE_API_KEY]`。`functions/oshi_news/video_search.js` に中身、`functions/index.js` に関数を足す。

### 6.3 アプリ

- `lib/repositories/oshi_news_repository.dart` に `searchVideos(String personId)`（Callable を呼ぶ。`FirebaseFunctions.instanceFor(region: 'asia-northeast1')`）。
- `lib/providers/oshi_news_providers.dart` に `personVideosProvider`（`FutureProvider.autoDispose.family<PersonVideos, String>`）。
- 推しのページ（`lib/features/oshi/oshi_detail_page.dart`）：個人で `youtubeUrl` が null のとき、`_Videos` の代わりに `_PersonVideos`。見出し「YouTube の動画」、その下に小さく「YouTube で「◯◯」を検索した結果です（公式とは限りません）」。動画の行は `VideoNewsRow` と同じ形（サムネイル・タイトル・チャンネル名と日付）。見出しの右に「YouTube で検索」（検索結果のページを開く）。読み込み中はくるくる、失敗・0件なら区画ごと出さない。

## 8. 確認すること

1. グループの「メンバーをまとめてフォロー」を押すと、メンバー全員が一度に「フォロー中」になる。
2. 推しの札・所属・申請中・受付の種別などのチップが読みやすい大きさになり、行が崩れない（推しの一覧・ライブ詳細・グッズ交換）。
3. ライブ一覧の見出しが「今後参戦するライブ」になり、横長では右の列に「推しの今後のライブ」が出る。縦長では今の順。
4. ホームで、フォロー中の推しの最近登録されたライブのうち、まだ一覧に無いものが「推しの新しいライブ」に出る。「参戦する」で一覧に入り、カードが消える。横長では右の列の当落発表の下、縦長では当落発表の後に出る。
5. CUTIE STREET のメンバーのページに「YouTube の動画」（検索の結果）と X が出る。24時間以内にもう一度開いても、Functions のログで API を呼んでいない（キャッシュ）。
