## 3. 決定事項：推しページ（Fc-1・Fc-2。完了）
 
### 3.1 絞り込み
 
- 見出し「フォロー中の推し」の下に「すべて（n）」「グループ（n）」「個人（n）」のチップ。選んでいるものは墨の地に紙の文字、選んでいないものは白の地に墨の文字（枠は墨 2px の丸）。
- 最初は「すべて」。覚えない。選んだ種別に1件も無いときは「フォロー中のグループはありません」「フォロー中の個人はいません」。
### 3.2 最推し
 
- 1つだけ。保存先 `users/{uid}/settings/favoriteOshi`（`kind`：`group`／`person`、`id`、`updatedAt`）。外すときはドキュメントを消す。
- フォロー中の一覧の各行で、「フォロー中」ボタンの左に☆／★（★は `BrandColors.hall2`）。☆で最推しにする（置き換え）、★で外す。
- 「推しを探す」の下に見出し「最推し」と白い箱（★・名前 20・チップ。グループなら押すとメンバーのシート）。いないときは箱を出さず、一覧の上に「☆を押すと最推しにできます」。
- 最推しのフォローを外したら最推しも外す（失敗しても無視）。フォロー中でない最推しは表示しない。
## 4. 決定事項：推し（Fc-3・Fc-4）
 
### 4.1 グループのメンバーをその場で開く（Fc-3）
 
- グループの行を押すと、すぐ下にメンバーが開く。もう一度押すと閉じる。複数のグループを同時に開ける。開いた状態は覚えない。
- グループの行のチップ「メンバーを見る ›」は「メンバー ▼」（開いているときは「メンバー ▲」）にする。
- 開いた部分：左に字下げ（28）し、左端に墨 2px の縦線。中身は上から
  1. 「メンバー全員をフォロー（n人）」のボタン（4.2）
  2. メンバーの行（`OshiListTile`。フォローのボタンあり。星は出さない）
  3. 「メンバーを申請する」（今のシートと同じく、このグループを所属に選んだ申請画面を開く）
- メンバーの並びと表示は今のシートと同じ（承認済み → 申請中、それぞれ名前順。所属グループのチップ）。メンバーがいなければ「まだメンバーが登録されていません」。
- 使う場所：推しページの「フォロー中の推し」（Fc-3）、推しを探す（Fc-4）。最推しの箱（グループ）は今のままシートで開く。
- 並べ方・フォローの処理は、シートと開く形で共通にする（`groupMembersOf(group, all)` を `oshi_list_tile.dart` か新しいファイルに置き、シートも使う）。
### 4.2 メンバー全員をフォロー（Fc-3）
 
- 対象は、承認済みで、まだフォローしていないメンバー。n はその人数。
- n が 0 なら「全員フォロー中」と出して押せない。
- 押すと1人ずつ順に `runFollowAction` でフォローする（途中は押せない）。失敗した人がいれば「n人はフォローできませんでした」、全員できたら「n人をフォローしました」と SnackBar で出す。
- フォローの上限（種別ごとに200）に達したら、そこで止めて、リポジトリの日本語の文を出す。
### 4.3 推しを探す画面の入れ子とアイコン（Fc-4）
 
- 検索の結果（検索語が空のときの全件も同じ）を、次のように並べる。
  - グループ：グループの行（4.1 で開ける）。
  - グループに所属する個人：その個人の行は単独では出さず、所属グループの行を出して**開いた状態**にする（検索でヒットした個人の名前を太字にする）。所属グループが複数なら、それぞれの下に出す。
  - 所属グループの無い個人：個人の行をそのまま出す。
  - 並びは、ヒットしたグループ・個人の今の順（`searchOshis` の結果の順）で、最初に出てきた位置に置く。
- アイコンを丸い札にして見分けやすくする（推しの行すべて。`OshiListTile`）。
  - グループ：墨の丸（直径 36）に白の `Icons.groups`
  - 個人：白の丸（直径 36、墨 2px の枠）に墨の `Icons.person`
  - Fc-7 で色があれば、丸の地（個人）・枠（グループ）にその色を使う。
## 5. 決定事項：掲示板・メモリー・色（Fc-5〜Fc-7）
 
### 5.1 掲示板の最新フィード（Fc-5）
 
- 推しの選択の先頭に「フォロー中すべて」を足し、**最初はこれを選ぶ**（フォロー中の先頭を自動で選ぶのをやめる）。`boardTargetProvider` が null なら「フォロー中すべて」とする。
- 「フォロー中すべて」のとき：フォロー中の推しと、フォロー中の個人の所属グループを重複なく対象にし、推しごとに今の検索（`openTradePostsProvider`）を行って `mergeBoardPosts` でまとめる（新しいプロバイダ `tradeFeedProvider(limit)`）。50件ずつ「もっと見る」は今と同じ。
- 推しを1つ選んだときは今と同じ（その推しの掲示板）。推しごとの絞り込みは、この選択で行う。
- 絞り込みに「グッズの種別」（`GoodsCategory`。複数選べる）を足す。投稿の譲の品目・求の対象（メンバー指定を除く）のどれかのグッズが、選んだ種別のどれかなら合う。種別は、対象の範囲のグッズ（`goodsInScopeProvider`）から `goodsId → 種別` を引く。引けないグッズは合わないとする。
- 「フォロー中すべて」のときは、特定のグッズと手渡しの公演の絞り込みは出さない（推しを決めないと候補が出せないため）。種別・譲／求・タグは出す。
- 投稿の作成で、掲示板の推しを対象の推しに選んでおく動き（Fa-4）は、推しを1つ選んでいるときだけ。
### 5.2 PC の横幅を使う（Fc-6）
 
- `HakoPageScaffold` に本文の最大幅 `maxContentWidth`（省略時は `kHakoContentMaxWidth`）を足す。
- メモリー一覧は、PC で `maxContentWidth: 1080`。本文の幅が 900 以上なら2列にする：左（幅の 2/5）に「参戦予定」、右（3/5）に「参戦済み」のカード。左右はそれぞれ別にスクロールする。900 未満は今の1列。
- ほかの画面（ホームなど）を2列にするかは 8章。
### 5.3 推しの色（Fc-7）
 
- 色は**個人の設定**とする（`users/{uid}/settings/oshiColors`：推しのキー → 色（ARGB の数）の Map と `updatedAt`）。共通データに入れるとルールの変更と編集の仕組みが要るため。
- 色を選べるのは、フォロー中の推し。推しページの行の、アイコンの札を押すと色のシート（`kThemeColorPresets` の12色と「色なし」）。
- 個人に色が無ければ、所属グループ（フォロー中かどうかは問わない）のうち、色があるものの最初の色を使う。どちらも無ければ色なし。
- 色を使う場所：推しの行のアイコンの札（4.3）、最推しの箱の★の代わりの札、掲示板の行の左端（4px の帯。投稿の対象の推しのうち最初に色があるもの）。
- ライブの一覧・ホームなどへの反映は 8章。
