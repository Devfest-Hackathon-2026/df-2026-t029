## 2. 今の作り（11/7 時点の `dev`）
 
- 個人（`oshis`）が所属グループの ID（`groupIds`）を持つだけで、グループ（`groups`）の側にはメンバーの一覧がない。
- この関係は「個人 → グループ」の向きにだけ使われている（個人を選ぶと、ライブを追加する画面・掲示板で、所属グループのライブ・投稿もまとめて出る）。
- 「グループ → メンバー」の向きは何もない。グループをフォローしてもメンバーは出ず、メンバーが1人もいないグループも申請できる。
- 推しの申請画面（`oshi_request_page.dart`）は、種別の選択が「グループ／個人」の順で、初期値がグループ。
- フォロー中の推し（`followingOshisProvider`）は、グループと個人をまぜて名前順に並べている（推しの画面・掲示板の推しの選択・投稿の対象の推しで使う）。
- 個人を申請するとき、所属グループには承認済みのグループしか選べない（`FirestoreOshiRepository.request` が確かめる）。
## 3. 決定事項
 
### 3.1 個人を先にする（Fb-1）
 
- 推しの申請画面の種別を「個人／グループ」の順にし、初期値を個人にする。
- フォロー中の推し（`followingOshisProvider`）を、個人を先、グループを後に並べる（それぞれ名前順）。
  - これで、推しの画面のフォロー中の一覧、掲示板の推しの選択（初期選択は先頭なので個人になる）、投稿の対象の推しのチップが、個人から並ぶ。
### 3.2 グループのメンバーを見る（Fb-2）
 
- 推しを探す・フォロー中の一覧で、**グループの行を押すと、メンバーの一覧のシート**を出す（`lib/features/oshi/group_members_sheet.dart`・新規、関数 `showGroupMembersSheet(context, group)`）。
  - メンバー：`allOshisProvider` のうち、個人で `groupIds` にそのグループの ID を含み、承認済みのもの。名前順。
  - 各メンバーの行は、今の `OshiListTile`（フォロー／フォロー中のボタン付き）を使い、シートの中でそのままフォローできる。
  - シートの上に、グループ名と「メンバー N人」を出す。
  - メンバーが0人なら「まだメンバーが登録されていません」と出す。
  - グループが承認済みなら、一番下に「メンバーを申請する」ボタンを出す。押すと、シートを閉じて、申請画面を「種別：個人、所属グループ：このグループ」を選んだ状態で開く（`/oshi/request?group=<グループの ID>`）。
  - 申請中のグループでは、「申請中のグループです。承認されるとメンバーを申請できます」と出し、ボタンは出さない。
- `OshiListTile` に、押したときの動き `onTap`（任意）を足す。グループの行にだけ渡す。
- 個人の行には、所属グループの名前を「所属：ステラノート」のラベルで出す（`OshiListTile` に `groupNames`（任意、文字列の配列）を足す。推しを探す・フォロー中・メンバーのシートで渡す）。
- ルート `/oshi/request` で、クエリ `group` を受け取り、`OshiRequestPage(initialGroupId: …)` に渡す。`initialGroupId` があれば、種別を個人にし、所属グループに入れておく。
### 3.3 グループの申請でメンバーも入れる（Fb-3）
 
- 申請画面で種別がグループのとき、「メンバー（任意・20人まで）」の欄を出す。名前を1人ずつ入れる欄で、「メンバーを追加」で増やし、× で消せる（別名の欄と同じ作り）。
- 申請すると、グループと、入力したメンバー（個人）を**1回のバッチで**作る。
  - メンバーは `status: pending`、ジャンルはグループと同じ、`groupIds` は新しいグループの ID だけ、`createdBy`・`createdAt` はグループと同じ。名前以外の項目は入れない。
  - リポジトリに `requestGroupWithMembers(OshiRequest group, List<String> memberNames, {required String uid})` を足す（`OshiRepository` と `FirestoreOshiRepository`）。グループの検査と重複の確認は今の `request` と同じ。メンバーは、名前が空でないこと・50文字以内であること・同じ申請の中で名前が重ならないことだけを確かめ、既存の推しとの重複は確かめない（同じ名前の別人がいるため）。
  - 申請中のグループを所属に持つ個人は、`firestore.rules` では作成できる（グループの存在を確かめていない）ので、ルールは変えない。
- メンバーの欄が空なら、今と同じくグループだけを申請する。

## 6. 確認すること（最後にまとめて）
 
- Fb-1：申請画面の初期値が個人。推しの画面のフォロー中・掲示板の推しの選択・投稿の対象の推しで、個人が先に並ぶ。
- Fb-2：推しを探す・フォロー中でグループを押すとメンバーのシートが出て、そこでフォローできる。個人の行に「所属：◯◯」が出る。「メンバーを申請する」で、所属グループが選ばれた申請画面が開く。
- Fb-3：グループをメンバー付きで申請すると、グループとメンバーが申請中で作られ、推しを探すで申請中として出る。
