## 3. 決定事項

### 3.1 推し始めた日と誕生日（O-1）

- 推しごとの**個人の設定**。`users/{uid}/settings/oshiDays`：
  - `startDates`（map）：キー → 推し始めた日（`YYYY-MM-DD`）
  - `birthdays`（map）：キー → 誕生日（`MM-DD`。年は持たない）
  - `updatedAt`
- グループの「誕生日」は結成日として同じ項目に入れる（画面の文言を「結成日」にする）。
- 入れる場所：推しの設定のシート（`showOshiColorSheet`）の一番下に「記念日」の区画を足す。
  - 「推し始めた日」：日付を選ぶ（今日より後は選べない）。「外す」。
  - 「誕生日」（グループは「結成日」）：月と日を選ぶ（`DropdownButton` を2つ）。「外す」。
  - 選んだらすぐ保存する（シートは閉じない。色・絵文字・画像と違い、2つ続けて入れることが多いため）。
- シートの見出しを「<推しの名前>の設定」にする（札のツールチップも「色・絵文字・記念日」）。

### 3.2 「推して◯日」（O-1）

- 推し始めた日があれば、最推しの箱の名前の下に「推して123日」（太字）を出す。推し始めた日を1日目として数える（当日は「推して1日」）。
- フォロー中の一覧の行には出さない（行が長くなるため）。

### 3.3 記念日のお祝い（O-2）

- 記念日の種類（どれも今日の日付で判定する）：

| 種類 | 条件 | 文言の例 |
|---|---|---|
| 誕生日 | 今日が誕生日（`MM-DD`） | 「今日は星宮ルナの誕生日！」 |
| 結成日 | グループで、今日が結成日 | 「今日はステラノートの結成記念日！」 |
| 推し始めて◯年 | 今日が推し始めた日と同じ月日で、1年以上 | 「星宮ルナを推して2年！」 |
| 推して◯日 | 推した日数が 100 の倍数 | 「星宮ルナを推して300日！」 |

- 2月29日は、うるう年でない年は2月28日に祝う。
- ホームの区画「推しの記念日」（`lib/features/home/home_oshi_days.dart`）：あいさつのすぐ下。
  - **今日**の記念日を、推しの札（`OshiKindBadge`）と文言の箱で出す（ハコ色の黄色の箱。複数なら縦に並べる）。
  - **これから7日以内**の記念日を、小さく「あと3日：空野カナタの誕生日（11/11）」の行で出す（最大3件、近い順）。
  - 今日もこれからも無ければ、区画ごと出さない。
- 対象はフォロー中の推しだけ（フォローを外した推しの設定は残るが出さない）。

### 3.4 推しごとの推し活費（O-3）

- `ExpenseItem` に `liveId`（任意）を足す（チケット・遠征・ライブを選んだ手入力の出費に入れる）。
- 推し活費の画面（`expense_page.dart`）の種類別の棒の下に「推しごと」の区画を足す。表示中の月について：
  - フォロー中の推し（個人・グループ）ごとに、ライブの `oshiIds`・`groupIds` にその推しが入っている出費を合計し、多い順に棒で出す（棒の色は推しの色。無ければ墨）。
  - 複数の推しのライブの出費は、それぞれの推しに入れる（そのため、推しごとの合計を足すと月の合計より多くなることがある。区画の下に注記を出す）。
  - ライブに結び付かない出費・フォロー中の推しのいないライブの出費は「推しの指定なし」として最後に出す。
  - 金額が 0 の推しは出さない。
- 集計は `lib/utils/expense_by_oshi.dart`（純粋な関数）に置く。

## 6. 確認すること

1. 推しのシートで推し始めた日・誕生日を入れる → 最推しの箱に「推して◯日」。
2. 誕生日を今日にする → ホームのあいさつの下に「今日は◯◯の誕生日！」。3日後にする → 「あと3日」の行。推し始めた日を 99日前（今日で100日目）にする → 「推して100日！」。
3. グループでは「結成日」と出る。フォローを外した推しの記念日は出ない。
4. 推し活費の画面で、推しごとの棒が出る。複数の推しのライブの出費は両方に入る。ライブに結び付かない出費は「推しの指定なし」。
