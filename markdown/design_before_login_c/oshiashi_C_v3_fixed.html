PROBLEM 01

こんな「うっかり」、ありませんか?

推し活は楽しい分、気をつけることがたくさん。おしあしは、その「うっかり」を減らすためのアプリです。

申込期限、いつだっけ?

公式サイト、SNS、メール。告知があちこちにあって、期限を見落としてしまう。

当選したのに、入金を忘れた

当落発表のあとには入金期限があります。過ぎてしまうと、せっかくの当選が無効になることも。

ライブが増えて、整理できない

追いかける推しが増えるほど、日程も期限も増えて、頭の中だけでは管理しきれない。

FLOW

はじめての方も安心。申込・当落・入金、それぞれの意味から説明します。

PROBLEM 02

ライブ本番の前に、こんなことありませんか?

チケットが取れても、推し活の悩みはまだあります。ライブの日が近づくほど気になるのが、グッズのこと。

推しのグッズ、手に入らなかった

欲しかったグッズが売り切れていた、買いに行けなかった。ライブまでに何とか手に入れたい。

誰かとグッズを交換したい

自分が持っているグッズと、欲しいグッズを交換できたら。そう思っても、きっかけがない。

持っている人が、見つからない

お目当てのグッズを持っている人を、SNSの投稿から探し回るのは大変で、時間もかかる。

FAQ

よくある質問

スクショは、どんな画像を選べばいいですか?

公演名・日程・申込期間・入金期限などが写っている、告知画像やチケットサイトの画面です。登録する前に、読み取り結果を必ず確認してください。

フォローしたい推しが見つからないときは?

追加の申請を送れます。

「譲」「求」って何ですか?

グッズ交換で使う、ファンの間の言葉です。手放したいグッズは「譲」、探しているグッズは「求」として登録します。

ほかのファンが登録したライブは、どう使えますか?

同じ推しをフォローしているファンが登録したライブを、自分の一覧に追加できます。自分で入力する手間が省けます。
