案3

チケットを直接タップして直す

プレビューのチケットそのものをタップして編集する案です。見た目のまま直せるので、いちばん直感的です。

特徴

  • チケットの写真・セトリ・感想をタップすると、下から編集シートが開く
  • 空の部分には「+ セトリを書く」「+ 感想を書く」の枠が出る(この枠は投稿画像には出ない)
  • 「画像にのせる部分」「文章にのせる部分」を、ボタン形式で分けて選ぶ
  • 画像の形・デザイン・背景色は、折りたたみの中にまとめる

この3案の共通点

  • 案Cのチケット風の記録画面(座席は半券に表示)と、案Dのホームからの投稿を一本化
  • ホームのカードから、写真・セトリ・感想の編集、のせる部分の選択、文章、投稿までを1つの画面で行える
  • 投稿用の「チケット」画像を、切り取り線・半券・バーコード風の本物のチケットらしい見た目に変更
  • 座席はSNSには出さない。かわりにセトリと感想をのせられる
  • のせる部分を、XとInstagramで別々に、「画像に」「文章に」それぞれ選べる(初期設定は仮です)
  • 長いセトリ・感想は、画像に入る分だけ表示し、全文は文章にのせられる(その旨も画面に表示)

デモの使い方

  • ホームのカードの「Xに投稿」「Instagram」から編集画面へ。メモリー→チケットを開き、「まとめて編集して投稿」からも入れます
  • 先にセトリと感想を入れると、チケットと文章に反映されます
  • 画面上の切り替えで、Googleフォト未連携・座席情報なしの場合も確認できます
  • 写真は見本用のイラストです。「画像を保存」はデモ用の見せかけです

実装前に確認したいこと

  • Googleフォトの仕様:外部アプリが写真全体を自由に読めない方向に変わったと認識していますが、最新情報は未確認です。ユーザーが写真を選ぶ画面が必要か、公式情報で確認してください
  • Instagramは投稿文を自動入力できないため「画像を保存→文章をコピー→開く」の3ステップ。Xは文章入りの投稿画面を開けますが、画像は自動で付きません
  • チケット画像の生成方法(サーバー側で画像化するか、端末で作るか)は未決定です
