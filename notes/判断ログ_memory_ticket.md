## 12.0 の 5 の確認（Limited Use と Gemini への送信。2026-11-08、ユーザーが文面を提示）

## Gemini API の規約の確認（2026-11-08、ユーザーが文面を提示）

- **無料サービス**（Gemini API の無料枠。Spark のまま）: 送った内容は Google の製品・機械学習の改良に使われ、人間のレビュアーが確認する場合がある。「プライベート情報・個人情報を送らない」とある。→ **利用者の写真を送るのは不可**（Limited Use の「機能の提供に必要な範囲」を超える）。
- **有料サービス**（Cloud の請求先アカウントを有効化したプロジェクト）: プロンプト・画像・回答を製品の改善に使わない。不正使用の検出・法令対応のためだけに一定期間記録する。→ 写真を送れる。
- 結論（要ユーザーの判断）: 写真を Gemini に送るのは、**請求先アカウントを有効化した場合だけ**。案A: 請求先を紐づける（予算アラートを設定。無料トライアルのクレジットを使う）。案B: 請求先を紐づけず、写真えらびは Gemini を使わず、利用者が自分で選ぶだけにする（Picker は使える）。

## Gemini の請求先の判断（2026-11-08、ユーザー）

- **案A: 請求先アカウントを紐づける（Blaze に切り替える）**で進める。写真えらびは作ったとおり Gemini に縮小版を送る。
- 切り替え・予算アラートの設定は人間が行う（エージェントは行わない）。切り替わるまでは、写真を Gemini に送る動作確認（G0 ⑤）と本番での利用は行わない（偽物で開発する）。
- 捨てた案B（Gemini に写真を送らない）: 切り替えができなかったときの代案として残す（`PhotoPickAi` の差し替えで対応できる）。
- 影響: Step 6（Blaze 後）の前提が先に満たされる。Step 6 自体は今回の範囲外。
